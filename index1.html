1. HTML là gì?

HTML (HyperText Markup Language) là ngôn ngữ đánh dấu được sử dụng để xây dựng cấu trúc và nội dung của các trang web.

HTML không phải là ngôn ngữ lập trình. Nó sử dụng các thẻ (tag) để mô tả cho trình duyệt biết nội dung trên trang web được tổ chức như thế nào.

Ví dụ: HTML có thể được sử dụng để tạo tiêu đề, đoạn văn, hình ảnh, liên kết, bảng, biểu mẫu và nhiều thành phần khác trên trang web.

2. HTML5 là gì?

HTML5 là phiên bản hiện đại của HTML, được thiết kế để hỗ trợ tốt hơn cho các ứng dụng web hiện đại và nội dung đa phương tiện.

HTML5 cung cấp nhiều thẻ mới giúp xây dựng trang web có cấu trúc rõ ràng và có ý nghĩa hơn.

  • <header> – Phần đầu của trang.
  • <nav> – Khu vực điều hướng.
  • <main> – Nội dung chính.
  • <section> – Một khu vực nội dung.
  • <article> – Một nội dung độc lập.
  • <footer> – Phần cuối trang.

3. Cấu trúc cơ bản của một trang HTML

Một tài liệu HTML cơ bản thường có cấu trúc như sau: 

<!DOCTYPE html>
<html lang="vi">

<head>
    <meta charset="UTF-8">
    <title>Trang web của tôi</title>
</head>

<body>
    <h1>Xin chào!</h1>
    <p>Đây là trang web đầu tiên của tôi.</p>
</body>

</html>

4. Một số thẻ HTML phổ biến

  • Tiêu đề: <h1> đến <h6>
  • Đoạn văn: <p>
  • Liên kết: <a>
  • Hình ảnh: <img>
  • Danh sách: <ul>, <ol>, <li>
  • Bảng: <table>
  • Biểu mẫu: <form>

5. HTML kết hợp với CSS và JavaScript

Trong phát triển web, HTML thường được sử dụng cùng với CSS và JavaScript.

  • HTML: Xây dựng cấu trúc và nội dung.
  • CSS: Thiết kế giao diện, màu sắc, bố cục và hiệu ứng.
  • JavaScript: Tạo tính tương tác và xử lý các hành vi trên trang web.
Có thể hiểu đơn giản: HTML là bộ khung, CSS là phần trang trí và JavaScript là phần tương tác của một trang web.

6. Ưu điểm của HTML5

  • Cú pháp đơn giản và dễ học.
  • Được hỗ trợ bởi hầu hết các trình duyệt hiện đại.
  • Hỗ trợ nội dung đa phương tiện như video và audio.
  • Cung cấp các thẻ semantic giúp cấu trúc trang rõ ràng.
  • Phù hợp để xây dựng các website hiện đại.
  • Có thể kết hợp dễ dàng với CSS và JavaScript.

7. Kết luận

HTML là kiến thức nền tảng quan trọng đối với bất kỳ ai muốn học phát triển web. Việc nắm vững HTML giúp chúng ta hiểu cách một trang web được xây dựng và tổ chức.

Sau khi học HTML, bạn có thể tiếp tục tìm hiểu CSS để thiết kế giao diện và JavaScript để tạo ra các trang web có tính tương tác cao.
